# Student Card Management

โปรเจกต์ตัวอย่าง Python OOP สำหรับจัดการข้อมูลนักเรียนและแสดงบัตรนักเรียนแบบข้อความ

## ความสามารถ

- เพิ่ม แสดงรายการ ค้นหา แก้ไข และลบข้อมูลนักเรียน
- แสดงบัตรจากรหัสนักเรียน
- บันทึกข้อมูลลง `data/students.json` และโหลดกลับเมื่อเปิดโปรแกรม
- ตรวจสอบฟิลด์ที่จำเป็นและป้องกันรหัสนักเรียนซ้ำ (ไม่สนตัวพิมพ์เล็ก/ใหญ่)

## เริ่มใช้งาน

ต้องมี Python 3.10 ขึ้นไป ไม่ต้องติดตั้งแพ็กเกจเพิ่มเติม

จากโฟลเดอร์โปรเจกต์ รัน:

```powershell
py -m student_card
```

ทำตามเมนูบนหน้าจอ ข้อมูลจะถูกสร้างใน `data/students.json` หลังเพิ่มนักเรียนคนแรก

## รันทดสอบ

```powershell
py -m unittest discover -s tests -v
```

## โครงสร้างโปรเจกต์

```text
student_card/
  __main__.py    จุดเริ่มต้นสำหรับรันด้วย python -m
  app.py         เมนูและการโต้ตอบกับผู้ใช้
  card.py        การแสดงผลบัตรนักเรียน
  models.py      โมเดล Student และการตรวจสอบข้อมูล
  repository.py  การอ่าน/เขียนข้อมูล JSON
tests/
  test_student_card.py
```
